# fn-finstat 财务统计｜项目需求文档

## 1 项目概述

### 1.1 项目目标

开发飞牛OS（fnOS）FPK 原生 Web 应用，基于 FastAPI + SQLite，实现微信支付、支付宝账单导入解析、消费流水管理、收支统计可视化，用于个人家庭财务支出统计。应用遵循飞牛应用开放平台开发规范，可打包为 fpk 安装包部署在 fnNAS。

### 1.2 适用环境

- 目标平台：飞牛OS（fnOS）x86_64 / arm64（platform=all）
- 本地开发环境：Debian / WSL / Linux，Windows（Python）
- 应用类型：Web 服务型 FPK 原生应用（端口服务 8090）

### 1.3 参考规范

飞牛应用开放平台开发文档：https://github.com/LarryMKott/fnnas-docs

## 2 功能性需求

### 2.1 文件导入与解析模块

1. 支持微信支付账单（.xlsx）导入，自动跳过头部说明行，提取交易时间、交易对方、金额、收支类型、交易单号、备注。
2. 支持支付宝账单（.csv）导入，GBK 编码自动处理，跳过表头说明行，提取交易字段。
3. 解析后标准化统一数据结构，输出统一账单记录字典。
4. 交易单号作为唯一主键，重复导入相同流水自动跳过，不重复入库。
5. 支持基础自动分类：商户关键词匹配自动填充消费分类，可扩展规则。
6. 导入结果返回统计：总解析条数、新增入库条数、跳过重复条数。

### 2.2 账单流水管理模块

1. 分页查询账单流水，支持筛选条件：时间起止、账户类型（微信/支付宝）、收支类型（收入/支出/转账）、消费分类。
2. 手动新增单条账单记录，填写交易时间、商户、金额、分类、备注。
3. 编辑已有账单，修改分类、商户、金额、备注。
4. 删除单条账单记录。

### 2.3 消费分类管理模块

1. 预置基础分类：餐饮、交通、购物、住房、医疗、娱乐、其他。
2. 查询全部消费分类列表。
3. 支持新增自定义分类，分类名称不可重复。

### 2.4 统计报表模块

1. 收支汇总统计：收入总额、支出总额、净结余。支持按时间范围、账户筛选。
2. 月度收支趋势：按月聚合收入/支出，返回图表结构化数据。
3. 分类支出饼图：按消费分类聚合支出金额，用于前端饼图展示。
4. 商户消费 TOP 排行：按商户支出金额降序排序，取 TOP N。

### 2.5 数据持久化

1. 数据库使用 SQLite 单文件，无需额外数据库服务。
2. 飞牛OS 环境：数据库文件存放在 `TRIM_PKGVAR/finance`，升级、卸载应用保留用户数据。
3. 临时上传文件存放在 `TRIM_PKGTMP` 目录，系统自动回收清理。

## 3 非功能性需求

1. **兼容性**：Web 前端兼容 PC 浏览器、移动端浏览器；后端监听 `0.0.0.0:8090`。
2. **性能**：单次导入支持至少 10000 条账单记录；分页查询保证响应速度。
3. **稳定性**：账单导入使用事务，解析异常时回滚，避免半入库脏数据。
4. **安全**：仅本地访问，无用户鉴权（单机个人账本）；限制上传文件大小最大 10MB；校验文件后缀。
5. **部署规范**：严格遵循 fnOS FPK 规范，使用平台注入 TRIM_* 环境变量，禁止硬编码绝对路径。
6. **可扩展性**：解析器使用抽象基类，后续可新增银行卡、其他平台账单解析。

## 4 数据模型定义

### 4.1 bills 账单流水表

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增主键 |
| tx_time | TEXT | 交易时间字符串 |
| account | TEXT | 账户类型 wechat / alipay |
| tx_type | TEXT | 类型 expense支出 / income收入 / transfer转账 |
| merchant | TEXT | 交易对方/商户名称 |
| amount | REAL | 金额，正数 |
| category | TEXT | 消费分类名称 |
| tx_id | TEXT UNIQUE | 交易唯一流水号 |
| remark | TEXT | 备注信息 |

### 4.2 categories 消费分类表

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增主键 |
| name | TEXT UNIQUE | 分类名称 |

## 5 接口需求定义

见 README.md 中 API 接口清单，使用 RESTful 风格，JSON 格式交互，FastAPI 自动生成 OpenAPI 文档。

## 6 约束与限制

1. 仅支持官方导出的微信 xlsx 账单、支付宝 csv 账单；非标准自定义格式不保证解析成功。
2. 无多用户隔离，单账本，适合个人使用。
3. 不提供云端同步，所有数据保存在本地 fnOS 机器内。
4. FPK 应用权限等级为 normal 普通权限（专用应用用户运行）。
