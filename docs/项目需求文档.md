## 1 项目概述

### 1.1 项目目标

开发飞牛OS（fnOS）FPK 原生 Web 应用，基于 FastAPI + Vue 3，实现微信 / 支付宝 / 京东 / 云闪付账单导入解析、消费流水管理、预算与净资产追踪、收支统计可视化，并接入 DeepSeek 提供智能分类与月度消费报告。应用遵循飞牛应用开放平台开发规范，可打包为 fpk 安装包部署在 fnNAS。

### 1.2 适用环境

- 目标平台：飞牛OS（fnOS）x86_64 / arm64（platform=all），经统一网关访问
- 本地开发：Windows / Linux / macOS（Python ≥ 3.9 + Node.js ≥ 18）
- 应用类型：Web 服务型 FPK 原生应用（独立部署端口默认 8090；统一网关模式走 Unix Socket，不占 TCP 端口）

### 1.3 参考规范

飞牛应用开放平台开发文档：https://github.com/LarryMKott/fnnas-docs

## 2 用户与账号模型

| FR | 需求 |
| --- | --- |

| FR-U.2 | 升级前的历史无归属流水归入默认账号（空串），用户可在设置页一键认领到当前账号 |

## 3 功能性需求

### 3.1 账单导入与解析

| FR | 需求 |
| --- | --- |
| FR-I.1 | 支持微信支付 xlsx、支付宝 csv（GBK）、京东金融 csv、云闪付 csv 四平台账单；列头别名宽容匹配，容忍平台版本微调；自动跳过说明/表头前导行 |
| FR-I.2 | 多编码探测（UTF-8-SIG / UTF-8 / GB18030），坏字节兜底解码 |
| FR-I.3 | 金额清洗（货币符号/千分位/后置负号）、收支类型判定、交易关闭类状态行跳过 |
| FR-I.4 | 交易单号全局唯一去重（空单号转 NULL），重复导入自动跳过并计数 |
| FR-I.5 | 关键词自动归类：未命中归入「其他」；启用 AI 时对「其他」记录二次语义归类，任何 AI 失败不影响导入 |
| FR-I.6 | 导入涉及的分类不存在时自动创建（幂等） |
| FR-I.7 | 导入结果返回统计：解析总数 / 新增 / 重复跳过 / AI 归类条数；全过程写运行日志 |
| FR-I.8 | 上传文件限制 10MB，校验后缀；上传与 NAS 导入共用同一解析管线 |

### 3.2 NAS 目录导入

| FR | 需求 |
| --- | --- |
| FR-N.1 | 设置 NAS 上的账单目录（绝对路径）后，可浏览目录（含子目录）并按文件导入，支持一键批量导入 |
| FR-N.2 | 文件来源自动识别：按表头特征列打分判定平台，识别不出回退文件名关键字；仅展示 csv / xlsx |

## 4 非功能性需求

| # | 需求 |
| --- | --- |
| NFR-1 | **兼容性**：PC 与移动端主流浏览器；三数据库方言行为一致（唯一键去重、幂等迁移） |
| NFR-2 | **性能**：单次导入 ≥ 10000 条；地域识别 2 万条 ≤ 5 秒；日志查看只读尾部不大文件整读 |
| NFR-3 | **稳定性**：导入全程事务，解析异常回滚不产生半入库脏数据；AI 失败、单批失败均降级不阻断 |

| NFR-5 | **部署规范**：严格遵循 fnOS FPK 规范（manifest、config/*、cmd/*、wizard/、ICON）；数据全部存 `TRIM_PKGVAR`，禁止写 `TRIM_APPDEST` |
| NFR-6 | **可扩展性**：解析器抽象基类 + 别名表驱动，新增平台只需注册；迁移函数按版本登记 |

## 5 数据模型（schema v3）

| 表 | 说明 |
| --- | --- |
| `bills` | 流水：id、user_id、tx_time、account（wechat/alipay/jd/unionpay）、tx_type、merchant、amount、category、tx_id（全局唯一，可空）、remark、tags、reimbursed、deleted（软删除） |

| `budgets` | 月度预算：user_id + month + category 唯一（category 空串 = 总预算）、amount |
| `asset_snapshots` | 资产快照：user_id、snap_date、name、asset_type（asset/liability）、amount、remark |
| `app_meta` | 键值元数据（schema 版本戳） |

## 7 约束与限制

1. 仅保证官方导出的四平台账单文件可解析；非标准自定义格式不保证成功。
2. 多账号隔离依赖网关转发的可信身份头；独立部署直接开放端口时身份头可被伪造（README 已声明风险），多用户场景必须经统一网关访问。
3. 不提供云端同步，数据保存在本地 fnOS 或用户自建的外部数据库内。
4. 消费地图基于商户文本推断，存在识别率上限，界面如实展示而非伪造完整分布。
5. FPK 应用权限等级 normal（专用应用用户运行）。
