# 前端开发规范

> 适用目录：`frontend/`
> 配套：[Git提交规范.md](Git提交规范.md) · [界面设计方案.md](../界面设计方案.md) · [重构说明.md](../重构说明.md)
> 与 `frontend/eslint.config.js`、`frontend/.prettierrc.json`、`frontend/src/assets/style.css` 严格对应

## 1. 技术栈与硬约束

| 项 | 选型 |
| --- | --- |
| 框架 | Vue 3.5（`<script setup>`，不用 Options API） |
| 构建 | Vite 8（产物输出 `app/static`，`base: "./"`） |
| 图表 | ECharts 6（经 `src/utils/charts.js` 引入） |
| 宿主集成 | `@trimjs/web-app`（飞牛 fnOS SDK，见 `src/fnos.js`） |
| 状态 | 原生 `reactive`/`ref`，**无 Pinia / Vuex** |
| 路由 | **无 vue-router**，切换靠 `store.tab` + `App.vue` 条件渲染 |
| 语言 | JavaScript + JSDoc，**无 TypeScript** |
| 工具 | ESLint 9（flat）+ Prettier 3：`npm run lint` / `npm run format` |

**硬约束**：

1. 接口前缀在**运行时**从页面 URL 推导（向导参数 `wizard_api_base_path` 可改），**禁止构建期写死 base 或硬编码 `/api`**，统一走 `src/api/client.js`
2. 应用以 iframe 嵌入飞牛桌面，可能在 fn Connect 子域/独立端口（跨域），**不得假设能读宿主 localStorage**，主题探测走 `src/fnos.js` 多源降级链

**放置规则**：

| 内容 | 位置 |
| --- | --- |
| 新的后端接口调用 | `src/api/<域>.js`（按域直接 `import`，**没有统一出口文件**） |
| 可复用逻辑（无模板） | `src/composables/useXxx.js` |
| 纯函数 | `src/utils/` |
| 跨组件共享状态 | `src/store.js`（**仅确实跨组件时**） |
| 仅本组件使用的状态 | 组件内 `ref`/`reactive`，**不塞 store** |
| 业务常量/枚举 | `src/utils/constants.js`（单一来源） |

## 3. 组件

- 文件名 **PascalCase**（`BillsPanel.vue`），子域放子目录（`components/settings/AICard.vue`）
- 一律 `<script setup>`；顺序固定：`<script setup>` → `<template>` → `<style scoped>`
- **每个组件顶部写"设计意图"注释**（解决什么问题、改造重点）
- 样式必须 `<style scoped>`

**导入顺序**（空行分组）：

```js
import { computed, reactive, ref, watch } from "vue";          // 1. vue
import { listBills, deleteBill } from "../api/bill";            // 2. api
import { fmtSignedMoney, amountClass } from "../utils/format";  // 3. utils
import { ACCOUNTS, TX_TYPES } from "../utils/constants";
import { confirm } from "../composables/useConfirm";            // 4. composables
import { isBusy, runTask } from "../composables/useLoading";
import { categories, store } from "../store";                   // 5. store
import { toast } from "../toast";                               // 6. toast
import AppIcon from "./AppIcon.vue";                            // 7. 子组件
```

**Props / Emits**：

```vue
<script setup>
const props = defineProps({
  bill: { type: Object, required: true },
  readonly: { type: Boolean, default: false },
});
const emit = defineEmits(["saved", "close"]);
</script>
```

- Props 声明 `type` + `default`；对象/数组默认值用工厂函数 `() => []`
- 不在子组件直接改 props，通过 `emit` 通知父组件

**图标**：统一 `<AppIcon :name="..." :size="18" />`，**禁止模板里写 emoji 或文字符号**（♻、✕）。新增图标往 `AppIcon.vue` 的 `PATHS` 加 `d` 序列。

## 4. 状态管理

**无 Pinia**，`src/store.js` 只放真正跨组件共享的状态：

```js
export const store = reactive({ tab: "dashboard" }); // 当前标签页
export const categories = ref([]);                   // 分类列表
```

- 只有多组件共享才进 store
- 共享数据的刷新函数放 store（如 `refreshCategories()`）
- 页面切换用 `store.tab`，**不引入 vue-router**

## 5. 接口层

### 5.1 统一走 `api()`

`src/api/client.js` 已封装：地址推导、超时（默认 30s）、响应解包、错误码翻译。

```js
// src/api/bill.js
import { api, apiUrl, toQuery } from "./client";

export const listBills = (params = {}) => api(`/api/bill/list${toQuery(params)}`);
export const deleteBill = (id) =>
  api(`/api/bill/${encodeURIComponent(id)}`, { method: "DELETE" });
// 下载链接：浏览器直接访问，不走 api() 解包
export const exportBillsUrl = (params = {}) => apiUrl(`/api/bill/export${toQuery(params)}`);
```

- `api()` **成功返回 `data`（204 返回 `null`），失败抛 `Error`**；组件层 `catch` 后 `toast(err.message)`，**不要自己判断 `res.code`**
- 长耗时请求（导入、AI 报告）在调用处放大 `timeout`
- URL 里的 id 必须 `encodeURIComponent`；查询参数用 `toQuery()`（自动跳过空值）
- **禁止组件里直接 `fetch`**，新接口加到 `src/api/<域>.js` 后按域 import（如 `from "../../api/update"`）

### 5.2 错误处理

```js
try {
  await deleteBill(id);
  toast("已删除");
} catch (err) {
  toast(err.message, true);           // 第二个参数 true = 错误样式
}
```

`err` 上可能带 `err.code`（后端错误码）与 `err.status`（HTTP 状态码），需按状态码分支（如 403 静默降级）时读 `err.status`。

## 6. 异步与竞态（重点）

### 6.1 耗时任务统一走 `runTask`

**禁止组件里散落 `busy`/`loading` 布尔标志**，一律用 `src/composables/useLoading.js`：

```js
const data = await runTask({
  key: "bills:load",        // 任务唯一标识（防重入 / 按钮 disabled）
  title: "加载流水",
  detail: "正在查询第 2 页…",
  mode: "latest",           // 查询类用 latest；写入类用默认 queue
  silent: false,            // 小请求可 silent: true，不弹 HUD
  task: async (update, isCurrent) => {
    update("正在查询…");
    const res = await listBills(params);
    if (!isCurrent()) return null;   // 已被同 key 新请求接管：旧响应作废
    update({ detail: `共 ${res.total} 条`, progress: 100 });
    return res;
  },
});
```

- `mode: "queue"`（默认）：同 key 拒绝重入，适合写入
- `mode: "latest"`：新请求接管，适合分页/筛选查询
- 按钮防重复点击：`:disabled="isBusy('bills:load')"`
- 失败时 HUD 显示错误并**原样抛出**，业务侧 `try/catch` 不用改

### 6.2 旧响应不得覆盖新响应

`latest` 模式只接管 HUD 状态，**不会取消在途 Promise**，异步回调必须自判"是否最新"：

```js
let loadSeq = 0;
async function load() {
  const seq = ++loadSeq;
  const res = await listBills(params);
  if (seq !== loadSeq) return;   // 已有更新请求，丢弃本次结果
  bills.value = res.items;
}
```

用 `runTask` 时等价写法是 `if (!isCurrent()) return null;`。

**凡 `await` 之后要写响应式数据的地方，都要有这个判定**，否则快速切换筛选条件会出现旧数据覆盖新数据。

## 7. 用户反馈

**禁止使用原生 `alert` / `confirm`**。

| 场景 | 用法 |
| --- | --- |
| 耗时任务进度 | `runTask({...})` → HUD 浮层（running/success/error/idle） |
| 轻提示 | `toast("已保存")` / `toast(err.message, true)` |
| 二次确认 | `if (!(await confirm({ title, message, danger: true }))) return;` |

`<AppToast />`、`<AppConfirm />`、`<AppLoading />` 已在 `App.vue` 挂载一次，**新组件不要再挂**。

失败反馈要说清原因：`toast(err.message, true)` 而非 `toast("操作失败")`。

## 8. 样式与设计令牌

### 8.1 四层令牌，组件只用第三层

`src/assets/style.css` 定义四层：

1. 基础调色板 `--pine-*` / `--paper-*` / `--ink-*` / `--brass-*` ← **禁用**
2. 语义色 `--income-*` / `--expense-*` / `--warn-*` / `--danger-*` ← **禁用**
3. **语义映射 `--color-*`** ← ✅ **组件只用这一层**
4. 尺度 `--space-*` / `--radius-*` / `--shadow-*` / `--z-*` / `--dur-*` / `--ease-*`

常用第三层令牌：

```
--color-bg  --color-surface  --color-surface-hover  --color-surface-sunken
--color-bg-elevated  --color-sidebar-bg
--color-text  --color-text-secondary  --color-text-tertiary  --color-text-inverse
--color-border  --color-border-strong  --color-divider
--color-primary  --color-primary-hover  --color-primary-soft  --color-primary-ring  --color-on-primary
--color-income / --color-income-soft    （收入：墨绿系）
--color-expense / --color-expense-soft  （支出：暖红系）
--color-success / --color-warn / --color-danger / --color-neutral （含 -soft 变体）
--color-input-bg  --color-input-border  --color-input-focus  --color-placeholder
--color-mask  --color-tooltip-bg  --color-tooltip-text
```

### 8.2 硬性禁止

- ❌ 硬编码颜色（`#fff`、`rgb(...)`）
- ❌ 裸 `z-index: 9999` —— 用 `--z-modal` / `--z-toast` / `--z-hud` / `--z-dropdown` / `--z-sticky` / `--z-overlay` / `--z-sidebar` / `--z-base`
- ❌ 裸 px 间距/圆角 —— 用 `--space-*` / `--radius-*`（含 `--radius-pill`）
- ❌ 组件内重写主题配色 —— 主题由 `html.dark` 类统一控制

### 8.3 收支色彩

**收入 = 墨绿系（`--color-income`），支出 = 暖红系（`--color-expense`）**，与主色 `--color-primary`（深墨绿 Pine）区分。不要按"红=亏损"的直觉写反。

金额展示统一用 `utils/format.js` 的 `fmtSignedMoney` / `amountClass`，不自己拼正负号与颜色类。

## 9. 图表

ECharts 一律通过 `src/composables/useChart.js`，**不要手写 init/resize/dispose 样板**：

```js
const chartEl = ref(null);
const { render } = useChart(chartEl, (chart) => {
  chart.setOption({ /* ... */ });
}, { canRender: () => store.tab === "dashboard" });
```

它已统一处理：容器可见性校验、ResizeObserver 自适应、卸载 dispose、主题切换重绘。

- 配色走 `src/utils/chartTheme.js`，跟随 `isDark`
- 面板隐藏时（`display:none`）传 `canRender` 跳过重绘，否则得到 0 尺寸画面
- ECharts 已拆为独立 chunk（约 628KB），**不要整包 import 到主包**

## 11. 响应式与性能

断点：`1180px` / `1024px` / `860px` / `640px` / `400px`，**主要分界 860px**。

- 表格类在窄屏切换为**卡片列表**（参考 `BillsPanel.vue`），不横向滚动宽表格
- 批量操作用**吸顶悬浮条**；行内操作收进 `RowActionsMenu`
- ECharts 保持独立 chunk；新增大依赖评估 `manualChunks`
- `vite.config.js` 已设 `chunkSizeWarningLimit: 700`，超过即需拆分
- 长列表分页加载（页大小常量定义在组件内，如 `PAGE_SIZE = 20`）
- 图标优先 inline SVG（`AppIcon`），不引图标字体

## 12. 安全与权限

- **前端不做权限的唯一依据**：后端有中间件 + 路由守卫双层防御，前端隐藏按钮只是体验优化
- 接口 401/403 时 `api()` 已给出可读文案，组件按需静默降级（读 `err.status`）
- 禁止把敏感信息（绝对路径、token）展示到界面——后端已脱敏，前端也不要二次拼装

## 13. 代码风格

Prettier 配置（`frontend/.prettierrc.json`，**不要改**）：printWidth 100 · singleQuote false（双引号）· semi true · tabWidth 2 · trailingComma all · endOfLine lf · vueIndentScriptAndStyle false

ESLint 基于 `eslint-plugin-vue` flat/recommended，项目自定义：

- `vue/multi-word-component-names: off` —— 面板类单词名（`DashboardPanel`）是本项目惯例
- `no-unused-vars` 忽略 `_` 前缀参数、忽略 catch 参数（兜底 catch 有意静默）

注释用中文，解释**为什么**；关键函数加 JSDoc（`useChart` 是范例）。

## 14. 测试

`npm test` 跑 `tests/**/*.test.mjs`（Node 原生 test runner，**不经过 Vite**）。

**新增测试文件放进 `tests/`、命名 `*.test.mjs` 即自动收录**——`package.json` 用 glob 而非硬编码文件名，不要改回去。

被测试直接 import 的模块：

- `import` 要**显式带 `.js` 后缀**（如 `from "../toast.js"`），否则 Node 无法解析
- 不依赖 `import.meta.env` 等 Vite 专有能力

> `npm test` **已接入 CI 门禁**，测试不通过会阻断流水线。

## 15. 构建产物

- **`app/static/assets/` 是产物，不入库**；`app/static/index.html` 与 `sw.js` 是源码，**必须入库**

## 18. 反例

```vue
<script setup>
import axios from "axios";                         // ❌ 项目无 axios，应走 src/api
const loading = ref(false);                        // ❌ 自造 busy 标志，应用 runTask
const items = ref([]);

async function load() {
  loading.value = true;
  const res = await axios.get("/api/category/list"); // ❌ 硬编码地址前缀
  items.value = res.data.data;                      // ❌ 无竞态判定，旧响应会覆盖新响应
  loading.value = false;
}

function onDelete(row) {
  if (confirm("确定删除？")) {                       // ❌ 原生 confirm
    axios.delete(`/api/category/${row.id}`).then(() => {
      alert("删除成功");                             // ❌ 原生 alert
    });
  }
}
</script>

<style scoped>
.card { background: #ffffff; z-index: 9999; }       /* ❌ 硬编码颜色 + 裸 z-index */
</style>
```
