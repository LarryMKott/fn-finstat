## 交付内容（S，纯前端布局重组，无接口变更）

设置页外壳（`SettingsPanel.vue`）由「10 张子卡片一屏平铺」改为 **4 个业务域分组 +
吸顶 chip 导航**。分组只是导航与视觉分层——子卡片组件零改动，仍各自管理状态
与加载时机，不引入新数据流。

| 分组（页面顺序：常用在前） | 收纳卡片 |
| --- | --- |
| 通用 | 外观 / 关于（AppearanceAboutCard） |
| 智能与自动化 | 智能分类（AI）/ 自动化 / 通知 |
| 数据与备份 | 当前数据库（含迁移）/ 账本管理 / 备份与恢复 |
| 安全与日志 | 开放 API Token / 操作审计 / 运行日志 |

导航与分组行为：

- **吸顶 chip 导航**：`position: sticky; top: var(--topbar-height)`（顶栏 60px
  sticky 之下），z 序取 `calc(var(--z-sticky) - 1)`，背景复用顶栏毛玻璃配方
  （color-mix + backdrop-blur），滚动时内容从导航下平滑穿过。
- **点击定位**：`scrollIntoView` 平滑滚动至分组锚点，分组节设
  `scroll-margin-top`（顶栏 + 导航高度）防遮挡；`prefers-reduced-motion`
  用户退化为直接跳转（与「无障碍」节的动效偏好承诺一致）。
- **scrollspy 反向高亮**：窗口级滚动 + rAF 节流，取「分组标题已滚过导航
  下缘」的最后一个分组为当前项；**滚动到底强制命中末组**（末组较短时顶部
  可能永远够不到探测线）；点击定位后 700ms 内锁高亮，避免平滑滚动途经中间
  分组导致 chip 闪烁；切换 tab 回设置页时 `nextTick` 重算（display:none →
  block 后位置测量才有效）。
- **移动端（≤860px）**：chip 导航横向滑动（隐藏滚动条，右缘截断示意可滑），
  卡片全宽堆叠；桌面端分组标题行 = 图标 + 标题 + 一句话范围说明。
- AppIcon 新增 `database`、`shield` 两个 Feather 风格图标（分组标识）。

## 顺手修复：CoachCard 两处存量 bug（dev 分支整页白屏根因）

起本地服务做视觉自查时发现应用**挂载即白屏**。经浏览器错误陷阱定位，
`CoachCard.vue`（T-1.6 引入）存在两处存量缺陷，任一都会让整个应用无法渲染：

1. 使用 `computed` 但未从 vue 导入（`ReferenceError`，模块求值即抛）；
2. `messages` 声明为 `reactive([])`，但全文 7 处按 `messages.value` 访问，
   渲染时 `undefined.filter` 抛 TypeError——修复取 `ref([])` 与既有用法对齐。

该缺陷自 9f4eb70 落地即存在（合并 cbeefd0 两侧均携带），影响所有基于 dev
分支构建的包：打开应用即整页空白。修复后看板页 AI 教练卡恢复渲染。
**已发布的 v1.1.x 包不受本次改动影响，但若从 dev 打包需包含本修复。**
