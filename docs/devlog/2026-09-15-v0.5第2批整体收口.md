## 收口项

### 1. REQ-ING-005「可导出」— 实现差异报告 CSV 导出

**复用**：`app/services/export_service.py` 的 `_csv_safe`（CSV 注入防护）；`app/utils/file_utils.py` 的 `content_disposition`。

**后端**（2 处）：
- `app/services/import_service.py` 末尾加 `export_details(details) -> tuple[str, bytes, str]`：列头 `交易单号/商户/金额(元)/原因`，复用 `_csv_safe`，文件名 `import-diff-YYYYMMDD-HHMMSS.csv`
- `app/api/upload.py` 加 `POST /api/upload/export-details` 端点：接收 `{details: ImportDetail[]}` body，返回 `Response(content, media_type, headers)`。数据来自请求体不依赖 db session

**前端**（1 处）：
- `frontend/src/components/ImportPanel.vue` 差异展示区加「导出 CSV」按钮，用 `Blob + URL.createObjectURL` 直接下载（前端已有 `importResult.details`，无需新 API 调用）

**测试**：
- `tests/test_api.py` 加 `test_export_details_csv`：复用重复导入场景，断言 content-type、表头、行数、`_csv_safe` 注入防护（reason="=EVIL" → 前缀单引号）

### 2. REQ-RPT-001 / T-6.5 报告数字可追溯 — 前端补附录展示

**现状**：后端已全交付（`ai_service.report_context_period()` 算所有数字、`AIReportGenerateResult.context` 回传、`ai_reports.stats_summary` 落库）。前端 `AIReportModal.vue` 存了 `preview.context` 但模板未渲染。

**前端**（1 处）：
- `frontend/src/components/AIReportModal.vue` 在 `report-md` 区块下加 `<details class="report-source"><summary>数据来源附录</summary><pre>{{ JSON.stringify(preview.context, null, 2) }}</pre></details>`（约 10 行 + CSS）
- 这是附录式追溯（展示全部 ctx 字段：区间/分类/商户/最大支出日等），满足"可看到来源数据"的最低验收口径。精细级"点数字看来源"留待 v0.6 NL 查询联动

**状态标记**：已实现（附录式追溯），加注「精细级点数字溯源待 v0.6」
