## 1. 问题现象

真机反馈：在飞牛「系统设置 > 应用 > 财务统计」里**看不到授权目录区域**，管理员无法为
本应用授权任何 NAS 目录。

飞牛帮助中心《文件权限如何设置和生效?》明确了该入口的存在与定位：

> **系统设置 > 应用**：适用于设置指定应用可访问的文件夹范围和权限，仅管理员有权限操作。

也就是说，这个区域本应默认存在。

## 2. 根因

`manifest` 第 16 行带着：

```ini
disable_authorization_path=true
```

- 该字段**自初始提交 `c563147` 就存在**，来自飞牛官方应用模板，全仓库仅此一处出现；
- 字段**没有任何公开文档说明**（官方文档站与全网检索均无定义）；
- 但字段名语义明确 —— `disable` + `authorization_path`，即"禁用授权路径"。

`true` 使飞牛隐藏了该应用的授权目录设置区域。由于字段来自模板且无文档，历次改
`manifest` 时都不会注意到它。

## 3. 修复内容

### 3.1 恢复设置入口（最小修复）

`manifest`：`disable_authorization_path=true` → `false`。

同时新增回归测试 `tests/test_host_integration.py::test_manifest_keeps_authorization_path_enabled`
锁死该字段，避免以后再被模板带回来。

### 3.2 接入应用共享授权（`trim.file.sharedAccess`）

只恢复入口有个缺口：管理员在设置里授权了目录，应用后端却从不读取它，用户感知不到
"设置生效了"。因此按官方《应用共享授权路径》补完整条链路：

| 层 | 改动 |
| --- | --- |
| `config/resource` | `api-scope` 增加 `trim.file.sharedAccess` |
| `app/services/trim_gateway.py` | 新增 `get_shared_accessible_folders()`（调用 `trim.file.getSharedAccessibleFolders`）；抽出 `_extract_paths()` 与用户目录查询共用清洗逻辑 |
| `app/services/nas_authorization_service.py` | 状态新增 `shared_folders` / `shared_reason` / `is_admin`；新增 `_fetch_shared_folders()`；`resolve_effective_import_dir` 优先级改为 旧配置 > 共享目录 > 个人目录 |
| `app/schemas/nas.py`、`app/api/nas.py` | 透出新字段 |
| `frontend/src/fnosAuth.js` | 新增 `sharedFolders` / `isHostAdmin` ref 与 `pickSharedDirectory()`（管理员可在本页直接授权） |
| `frontend/src/components/import/NasImportBox.vue` | 共享目录区块：列出管理员已授权目录，可一键「设为账单目录」；管理员额外看到「添加共享目录」按钮 |

### 3.3 两条设计取舍

**共享目录查询失败不拖垮整体。** `_fetch_shared_folders()` 永不抛，失败只填
`shared_reason`、留空 `shared_folders`，**不**把 `available` 打成 `False`。共享目录是
"可选加成"，一次抖动不该让用户的个人授权区整体变灰。

**旧配置优先级最高。** `resolve_effective_import_dir` 里，用户显式保存过的 `import_dir`
排在共享目录之前 —— 新能力不能顶掉既有数据；只有在"从没配过"的全新环境里，共享目录才
作为应用级默认值生效。

## 4. 安全边界（沿用官方文档约束）

官方《应用共享授权路径》明确：共享授权是授予**应用**的，不等于可以把内容给所有用户。
因此列表/写入前仍须按当前用户 `uid` 走 `check_user_acl`（已在 `check_path_acl` 中实现）。
本次改动**没有**放宽任何 ACL 判定，只是多了一个目录来源。

## 6. 遗留事项

- **`disable_authorization_path` 仍无官方文档佐证。** 本次是依据字段名语义 + 症状反推
  后修正，已在测试里锁死。用户重装 0.5.1 后需实测确认：设置页出现授权目录区域，且
  授权后导入页能列出该目录。
- **真机验证未完成**：本机无飞牛环境，共享目录链路（`pickSharedFile`、
  `getSharedAccessibleFolders`、管理员/非管理员分支）均只在单测层面覆盖。
