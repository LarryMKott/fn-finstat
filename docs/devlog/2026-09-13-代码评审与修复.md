### P2（重要缺陷）

- 恢复失败仍显示绿色「恢复完成」→ 补 ok/err 分支（`SettingsPanel.vue`）。
- AI 存量重分类为无上限同步请求 → 加 240 秒时间预算与「可再次点击续跑」提示（`ai_service.py`）。
- 消费地图/热力图在 `display:none` 容器上 init 得到 0 尺寸实例后永久空白 → 有数据且可见才渲染、`hasData` 翻转补 resize；两处图表加请求序号防竞态。
- 首屏内联主题脚本优先级（URL 优先）与运行时 `fnos.js`（宿主 localStorage 优先）相反 → 统一为后者，消除首屏闪跳。
- `detect.py` 无微信 CSV 特征列，NAS 目录里的微信 CSV 会被误判为京东 → 补微信特征列。
- 标签筛选使用 `func.concat`，旧版 SQLite（<3.44）无此函数 → 改为纯 LIKE 四分支并转义 `%`/`_` 通配符。
- 导出 CSV 未防公式注入 → `= + - @` 开头文本列加 `'` 前缀（金额列保持数值）。
- 图标资产不一致：新版设计未回写中性图标（`ICON.PNG`、`app/ui/images/icon_{64,256}.png` 仍是旧稿）→ `make_icons.py` 补中性版目标（日间配色重新生成）；删除 `frontend/public/icons` 下无引用的旧 `icon-64/256.png`。

### P3（打磨项，同批修复）

流水批量删除/还原/清空后页码回退；回收站单行还原不再覆盖多选集合；回收站模式隐藏假排序/假筛选；AI 报告弹窗改为显式点击才调用（避免打开即扣费）；422 校验错误显示具体信息而非 `[object Object]`；资产趋势加载失败 toast 提示；SW 缓存版本化（`SW_VERSION`，重建前端需递增）+ 导航 5xx 回退缓存；postMessage 仅接受父窗口来源；`theme.js` 死代码清理；`region_matcher` 恒真表达式清理；`.gitattributes` 增加 `*.bat text eol=crlf`（两个 bat 转 CRLF）并把 `set PYTHONUTF8` 移入 `setlocal`；`make_icons.py`/`preview_icons.py` 注解、docstring 与死参数修正。
