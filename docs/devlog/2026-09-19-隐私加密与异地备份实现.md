## 1. 配置敏感字段加密

### 加密方案（零新依赖）

HMAC-SHA256 CTR 模式流加密 + encrypt-then-MAC（先加密后认证），仅使用
Python 标准库（hashlib / hmac / os / base64）。不引入 `cryptography`
包——纯 SQLite 安装的 NAS 设备可能没有此包。

- 主密钥：`DATA_DIR/app_secret.key`（32 字节随机，首次启动自动生成，0600）
- 加密：`HMAC-SHA256(master_key ∥ "encrypt", nonce ∥ counter)` 作为密钥流，
  XOR 明文；`HMAC-SHA256(master_key ∥ "mac", nonce ∥ ciphertext)` 作为 MAC
- 格式：`enc:` + base64(nonce[16] + ciphertext + mac[32])；非 `enc:` 前缀
  按明文处理（向后兼容旧版数据）

### 覆盖范围

| 配置文件 | 敏感字段 | 加密 |
| --- | --- | --- |
| ai_config.json | api_key | ✅ |
| notify_config.json | webhook.url（含推送 Key） | ✅ |
| db_config.json | password | ✅ |
| remote_backup_config.json | password | ✅ |

存量迁移：file_settings 导入时自动检测旧版明文并重新加密（write-back）。
`db_config.json` 中的 password 在 `write_db_config_file` 写入时加密、
`_read_db_config_file` 读取时解密，旧版明文值原样返回由下次 save 重新加密。

### 密钥管理

- `app_secret.key` 32 字节随机，DATA_DIR 下，0600 权限；
- 首次启动自动生成；密钥文件被删除后下次启动重新生成（旧密文解密失败
  降级为原值，不崩溃——用户需重新保存配置以重新加密）；
- **密钥文件必须随 DATA_DIR 一起备份**，否则恢复后加密字段不可解。

## 2. 异地备份（WebDAV 推送）

- `remote_backup_service.py`：`push_backup(backup_json, settings)` 把
  `export_backup()` 的 JSON PUT 到 WebDAV URL；零新依赖（urllib.request
  标准 HTTP PUT + Basic Auth）；推送失败返回 {ok: false, message}；
- 配置存 `remote_backup_config.json`（webdav_url / username / password 加密）；
- 接口 `/api/remote-backup`（仅管理员）：GET/PUT 配置、POST 推送；
- 前端设置页异地备份卡片：WebDAV URL / 用户名 / 密码表单 + 推送按钮。
- 出站 Webhook（T-5.4 已有 Bark/ntfy/企业微信/通用）与异地备份（T-1.7
  WebDAV）共同构成完整的通知 + 灾备闭环。
