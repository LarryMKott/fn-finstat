## 1. 背景与范围

计划对 T-6.2 的要求：输入框 + 回答卡片（结论 + 图表 + 「依据」折叠区），回答卡片**必须展示查询口径**（时间范围、筛选条件、覆盖流水条数）；验收三条——支持追问（保留 3 轮上下文）、每个答案可一键「存为筛选」跳转流水页复现同样筛选、无数据 / 模型失败 / 越权三种异常均有人话提示。

T-6.1 交付时只有后端接口（`POST /api/nl-query` 单问单答），本次补齐对话层，并为「复现同样筛选」扩展流水接口的多值筛选能力。

## 2. 技术方案

### 2.1 追问上下文（后端）

- 请求体新增 `history: [{question, spec}]`（≤3 轮，`extra="forbid"`，条目夹带额外字段 422）；
- **回传的 spec 一律重新过白名单**（`_normalize_llm_spec`）：枚举、真实分类、长度、去重全部按新请求同等标准校验——自己上一轮的输出也不豁免篡改校验；
- **规则路径指代继承**（`_merge_followup`）：
  - 时间：本轮没有任何时间表达 → 继承上一轮（「那收入呢」沿用上月）；
  - 商户/分类：问题含指代词（那/这/它/该/上述…）且本轮未提及任何商户/分类 → 继承。门槛的目的是防止「收入多少」这类全新问题被静默套上旧口径；
  - 实际效果（重要）：**有可继承维度的追问全部在规则路径被截住**，零 LLM 成本、确定性、不耗日配额；LLM 路径只收到「无现成口径可继承」的问题，因此降级后无需再合并（无死代码）；
- LLM 路径把最近 3 轮问题与口径写进 system 提示词，指代由模型解析，输出仍过白名单；
- 响应新增 `inherited`（继承的维度列表），前端在卡片上标明「沿用上一问：时间、分类」。

### 2.2 存为筛选（口径复现）

问账口径是「时间 + 收支类型 + 多分类（IN）+ 多商户（OR 子串）」，流水页原有筛选只有单分类、无商户。为让「复现同样的筛选」不是近似：

- `GET /api/bill/list` 与 `/api/bill/export` 新增重复查询参数 `categories` / `merchants`（复用 `build_criteria` 既有分支，与 NL 查询同语义；条目去重、每值 64 字、≤10 条钳制）；
- 前端 `toQuery` 支持数组值逐项 append；
- 交接机制：`store.billsFilterHandoff`（QueryPanel 写入 → 切到流水页 → BillsPanel 激活时取走并清空），多值口径无常规控件，以虚线 chip 行展示（分类 X、商户含 Y）并可一键清除；`count` 指标落到流水页为「全部类型」。

### 2.3 回答卡片（前端 `QueryPanel.vue`）

- 新增「问账」导航项（账本组第 2 项，图标 sparkles；移动端 tab bar 含该入口）；
- 卡片结构：降级横幅（后端 message 原样）→ 结论（后端确定性文本）→ 口径 chip 行（时间/分类/商户/分组/覆盖笔数/沿用标记）→ 分组占比条（CSS bar，无画布）→ 截断提示 → 「依据」折叠区（按金额降序的流水样本表）→ 存为筛选按钮；
- 异常三种人话提示：无数据（后端「没有查询到流水」）、模型失败（降级横幅 + fallback message）、请求失败（错误卡片 + toast）；
- 空态给示例问题 chips，一键填入提问。

## 4. 测试与验证

- `tests/test_nl_query.py` 追问族 7 例：时间继承（「那收入呢」= 上月餐饮收入）、指代词商户继承（「那这个月呢」= 本月奶茶）、无指代词不继承商户/分类、篡改 spec 白名单收敛、LLM 提示词携带上下文（`test_llm_history_in_prompt`）、**追问零 LLM 成本**（已配置模型也不调用，`test_followup_rule_path_avoids_llm`）、接口层 history >3 轮 422 / 条目夹带字段 422；
- `tests/test_api.py` 1 例：多分类 IN + 多商户 OR 子串 + 组合 + 与单值参数并存 + 导出同口径；
- 全量后端 656 例通过；前端 lint / build（产物已更新）/ test 通过。

## 5. 已知边界与后续

- 追问继承是启发式口径（时间无条件继承、指代词触发范围继承），继承结果均在卡片口径行明示，用户可校验可改问；
- 分组结果用 CSS 占比条呈现，未用 ECharts（会话内轻量优先）；后续如需图表化可复用 `chartTheme`；
- LLM 路径的上下文解析覆盖面有限（仅当规则路径无可继承维度时才到达），这是成本上的有意取舍；
- v0.6 第 3 批剩余：T-6.5 精细级「点数字看来源」与 NL 查询联动；出口标准「新增用例 ≥ 25」已达成（T-6.1+T-6.3+T-6.4+T-6.2 合计远超）。
