## 交付内容

### 数据模型（schema v5 → v6）

- `notifications`：`user_id`（空串 = 应用级广播）、`event_type`、`event_key`
  （**唯一约束做事件去重**）、`title` / `content`、`push_status` / `push_error`
  （出站投递结果落库可查）、`created_at`
- `notification_reads`：每账号一行的**已读水位线**（`last_read_id`）。
  不存逐条已读明细：未读数 = 「id 大于水位线且对该账号可见」的行数，
  「全部已读」把水位线推到当前最大 id，广播类通知的已读状态按账号独立
- 迁移沿用 v4/v5 策略：纯新表由 `create_all` 幂等创建，迁移函数只推进版本戳；
  `tests/test_migration_v6.py` 复刻「v5 老库 → v6」升级路径

### 配置（`notify_config.json`，与 ai/nas 配置同策略明文存本地）

- `events`：五类事件逐类开关（`budget_exceeded` / `budget_near_limit` /
  `report_ready` / `import_done` / `task_failed`），未配置过的类型默认开启
- `webhook`：`enabled` + `type`（bark / ntfy / wecom / generic）+ `url`
- 界面**不回传 URL 明文**（`has_url` + `url_hint` 掩码，与 AI Key 同策略）；
  保存时 `url=None` 表示保持不变、空串表示清除

### 服务与出站（`app/services/notify_service.py`）

- `create_event()` 单一入口：开关检查 → 去重落库 → 出站推送（best-effort），
  **任何异常只记日志，绝不打断调用方**（调度器 / 目录导入 / 报告生成先干活）
- 出站渠道格式差异收口在 `_build_request()`：Bark 路径式 GET（标题/正文 URL
  编码）、ntfy 主题 POST（标题并入正文，规避 Header 非 ASCII）、企业微信机器人
  （errcode 业务码校验 + 2048 字节截断）、generic JSON POST
- SSRF 防线与 AI 通道同策略：仅 http(s)、**禁用重定向跟随**、10s 超时
- 事件去重键按「同一事件稳定相同」设计：预算 = 类型+账号+月+分类（每类每月至多
  一次）、任务停用 = 任务+停用时刻、导入完成 = 扫描轮次、报告就绪 = 账号+标题+时刻

### 事件生产者（本批实际挂接四类）

| 事件 | 挂接点 | 说明 |
| --- | --- | --- |
| `task_failed` | `scheduler._execute` 自动停用分支 | REQ-AUT-004 的「通知事件」收口 |
| `import_done` | `import_watch_service.scan_and_import`（新增流水 > 0 时） | 仅自动路径触发，手动上传用户在场不打扰 |
| `budget_exceeded` / `budget_near_limit`（80%） | 导入完成后 `check_budget_events(owner, 当月)` | 复用 `budget_service.overview()` 逐条判定 |
| `report_ready` | `ai_service.generate_report` 成功后 | 生成可达数十秒，用户可能已切走 |

### 接口（`app/api/notify.py`，两个 router 均已在 main 双前缀注册）

- `GET /api/notifications`（列表 + 未读数）、`GET /api/notifications/unread-count`
  （角标轮询）、`POST /api/notifications/read-all` —— 所有登录用户可用，
  写只动本人水位线
- `GET/PUT /api/settings/notify/config`、`POST /api/settings/notify/webhook-test`
  —— 读开放、写仅管理员；`_ADMIN_RULES` 与路由守卫双层同步
- webhook-test 的 `url` 缺省时回退用已保存配置（界面对已保存地址只回显掩码）

### 前端

- `api/notify.js`：通知接口封装
- `NotificationBell.vue`：顶栏铃铛 + 未读角标（99+ 封顶）+ 下拉通知面板；
  未读数 60s 静默轮询 + 页面可见时刷新；点击外部 / Esc 关闭
- `settings/NotificationCard.vue`：五类事件开关（改动即保存，失败重载回滚）+
  Webhook 表单（类型 / 掩码地址 / 发送测试 / 保存）
- `AppIcon.vue` 新增 `bell` 图标；事件类型展示名进 `utils/constants.js`
