## 交付内容（S：4 个只读工具，全部复用既有服务）

`mcp_service` 工具集由 4 个扩到 **8 个**，覆盖「收支 + 预测 + 健康 + 借贷」，
与开放 API 同一份查询口径（`user_id` 由身份链强制注入，跨账号天然隔离）：

| 新增工具 | 复用 | 文本输出 |
| --- | --- | --- |
| `query_forecast` | `forecast_service.cash_flow` | 起点余额（来源）、可变支出 P50/P90 月度水平、固定收支项逐条（含扣款日）、预测期末余额（P50/P90）；`horizon` 7-180 天可选 |
| `query_health` | `stat_service.health_score` | 总分与等级 + 三分项（储蓄率/负债率/应急金月数），缺数据分项如实提示（不造假数字） |
| `query_expense_structure` | `forecast_service.expense_structure` | 月均合计、必选项/可砍项月均与占比、固定项清单与可砍项 TOP（超出条数注明） |
| `query_loans` | `loan_service.list_loans` | 应收/应付未结汇总 + 逐笔进度（方向/对方/本金/已还/剩余/状态/到期日） |

实现细节：

- 工具经既有 `@tool` 装饰器注册，JSON-RPC 层（api/mcp.py）零改动——
  `tools/list` 与 `tools/call` 自动纳管新工具；
- 文本输出面向外部 Agent 做摘要（明细引导走 `query_bills` 翻页）；
  健康分项的储蓄率/负债率在纯文本中补 `%`（服务层 value 即百分数、unit
  为空串，界面渲染时自行补，纯文本不补会误读为小数）；
- 顶层导入 `forecast_service / stat_service / loan_service`（三者均不反向
  依赖 mcp_service，无导入环）。
